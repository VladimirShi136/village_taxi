# Рядом — такси для своих

Небольшой Flutter-прототип приложения для заказа такси в Берёзовке. Экран
показывает, как знакомые адреса, простые тарифы и локальный сервис могут
сложиться в понятный пользовательский сценарий.

## Возможности

- выбор адресов подачи и назначения, включая быструю смену местами;
- самобытная иллюстрация карты небольшого города без сторонних API и ключей;
- тарифы «Эконом», «Комфорт» и «Минивэн» с обновлением стоимости заказа;
- оформление заказа в демонстрационном режиме с явным предупреждением:
  реальный водитель не вызывается;
- адаптивный экран, который можно запускать в мобильном браузере и на desktop.

## Запуск

Установите Flutter stable, затем выполните:

```bash
flutter pub get
flutter run
```

## Проверки

```bash
flutter analyze
flutter test
```

## Технологии

- Flutter и Dart;
- Material 3;
- без сторонних пакетов, аккаунтов и API-ключей.

## Следующий шаг

Для реального сервиса можно добавить карты и геолокацию, регистрацию, серверный
поиск водителей, уведомления и панель диспетчера. Текущая версия намеренно
работает без сети и не отправляет реальные заказы.
